# FishSmart Pro — Faceless TikTok Content Scripts

*6 production-ready scripts for faceless vertical video. No on-camera presence required — screen recordings, voiceover (V.O.), animated text overlays, B-roll, and motion graphics only. Film in 9:16 vertical format. All screen recordings should use a phone screen recorder (Android) or browser window capture (desktop PWA).*

---

## Production Setup (All Scripts)

### Recording Equipment
- **Screen capture:** Phone native screen recorder (1080p minimum) or OBS Studio for web PWA
- **Voiceover:** Record V.O. separately using phone voice memo app or USB mic + Audacity (free). Aim for clean, conversational delivery.
- **Editing:** CapCut (free) or Premiere Pro

### Visual Assets to Prepare
- FishSmart Pro app loaded with a pre-planned location + species (pick one that gives a strong forecast: score 75+)
- Screen recordings of: forecast form, bite score reveal, factor breakdown scroll, lure recommendations, 12-hour activity chart, USGS water temp badge, history/export
- Competitor screenshots (Fishbrain pricing page, Navionics pricing page) — blurred where needed
- B-roll clips: lake drone footage, weather radar imagery, fishing lure close-ups, sunrise over water

### Typography / Overlay Style
- **Font:** Bold sans-serif (Montserrat Bold or CapCut default)
- **Colors:** White text with dark drop shadow for readability
- **Accent color:** Blue (#1B4D89) for key numbers, green (#2D8B5B) for positive stats
- **Text animation:** Pop-in / typewriter effect for key data points

### Music Notes
- Use trending instrumental beats (lo-fi, upbeat electronic) at low volume under V.O.
- SFX cues noted per script
- CapCut and TikTok native sounds work well — pick energetic, non-distracting tracks

## Batch Production Guide

### Recording Order (Suggested)

1. **Record all screen captures first** — Set up one good forecast (pick a location/species combo that scores 75+). Record every screen you need in one session: form input, bite score, factor scroll, lure card, activity chart, USGS badge, history page, pricing page.
2. **Record V.O. for all 6 scripts in one session** — Same mic, same room, same energy level. Takes 20-30 minutes total.
3. **Edit one script at a time** — Start with Script 6 (speed demo) since it's the fastest to assemble. Use it as your template for overlay styling.
4. **Export all at 1080×1920 vertical** — 30fps minimum, 60fps preferred for smooth scrolling.
